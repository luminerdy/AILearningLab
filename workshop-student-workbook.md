# AI Learning Lab ASK Workshop Student Workbook

Use AI to help with one useful task, then show why the result meets your goal. Save your requests and responses so you can explain what changed. Follow the class instructions for which tool to use; the activities use fictional event facts.

**Define → Direct → Check → Adjust**

Keep asking: **“What would convince me this is right?”**

## Event facts

Code and Create Club is holding an introductory meeting Thursday, 3:30–4:15 p.m., in Room 204. It is for students curious about making things with technology. Beginners are welcome and no coding experience is needed. Materials are provided, so students do not need to bring a device. Capacity is 20 students. Sign up with the club adviser by Wednesday. There is no fee.

## Exit ticket

1. What did you want to accomplish?
2. What information made your request more useful?
3. What specific evidence convinced you that a requirement was met?
4. What did you change after checking, and did it help?
5. What remains uncertain or needs another check?
6. What practice would help you next?
